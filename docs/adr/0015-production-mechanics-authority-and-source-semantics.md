# Production mechanics authority and source semantics

The Script API is the single production authority for Suspension Jump state, rider-scoped Pneumatic Shock Absorption, speed-scaled Tire Trample, and intent-gated horizontal Amphibious Flotation; native buoyancy uses its supported wave mode only for flotation. ADR-0009 already superseded ADR-0001's pure-data-only architecture; this decision also supersedes ADR-0007's test-only restriction on scripts, the native charged-jump portion of ADR-0010, the fixed `minecraft:area_attack` contact path in ADR-0008, the `player_controlled` buoyancy choice in ADR-0011, and the time-window interpretation of rider protection. An explicit Creative spawn egg invokes uniform Sixteen-Color Palette randomization, while the distinct Survival Vehicle Item places default red, explicit color events take precedence, and bare summons retain the red property default. Direct player-fatal dismantling is the only retrieval path and returns exactly one Vehicle Item; combat, explosions, fire, lava, and other fatal hazards use the Scrap loot path. These boundaries require stable `@minecraft/server` 2.10.0 because cancellable before-hurt and cross-device player-button events must be present rather than silently skipped.
