# Amphibious Flotation and Suspension Jump Mechanics

We decided to implement continuous liquid buoyancy across water and lava via `minecraft:buoyant`, native engine jump capability via `minecraft:can_power_jump`, `minecraft:horse.jump_strength`, and pre-tamed mount AI (`minecraft:is_tamed`, `minecraft:is_saddled`, `minecraft:behavior.player_ride_tamed`) replacing `input_ground_controlled` (which previously hardcoded Spacebar to dismount), and a dual-hybrid Script API physics layer that preserves forward momentum, enforces a 1.2-second pneumatic recharge cooldown, and triggers a downward `Crush Stomp` impact on landing. Spacebar is dedicated exclusively to Suspension Jump, and Left Shift (Sneak) is the dedicated vehicle exit key. Rather than dynamic hydroplaning or horse-style charged jumping, the massive 66-inch tires maintain continuous surface displacement (~0.8-block waterline) allowing swimming player boarding, lava lake navigation with elevated thermal rider shielding, airborne forest canopy demolition, and a downward crush stomp upon landing.
