# Amphibious Flotation and Suspension Jump Mechanics

We decided to implement continuous liquid buoyancy across water and lava via `minecraft:buoyant`, native engine jump capability via `minecraft:can_power_jump` and `minecraft:horse.jump_strength` (preventing Spacebar dismount while providing instantaneous vertical launch), and a dual-hybrid Script API physics layer that preserves forward momentum, enforces a 1.2-second pneumatic recharge cooldown, and triggers a downward `Crush Stomp` impact on landing. Rather than dynamic hydroplaning or horse-style charged jumping, the massive 66-inch tires maintain continuous surface displacement (~0.8-block waterline) allowing swimming player boarding, lava lake navigation with elevated thermal rider shielding, airborne forest canopy demolition, and a downward crush stomp upon landing.
